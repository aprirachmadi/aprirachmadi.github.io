Read the landscape twice.

Geo-Lens compares two spatially corresponding satellite images and produces a full-resolution, pixel-aligned mask showing where built surfaces are predicted to have changed.

Input
Two RGB observations
Output
1024 × 1024 binary mask
Model
Siamese U-Net · ResNet18
Try Geo-Lens View source

A reproducible change-detection pipeline and public prediction interface. The sample below is a stored prediction from the LEVIR-CD test split.

A landscape does not announce what changed.

Satellite images preserve a record of how places evolve. Geo-Lens reads the same place at two moments and turns their differences into spatial evidence.

Two observations, one coordinate system.

Each input is an RGB satellite image of the same geographic area. They must correspond spatially because every output pixel refers back to the same location.

Source and output resolution: 1024 × 1024 pixels.

Appearance is not always change.

Roof tone, vegetation, shadows, illumination, and slight registration differences can create visual movement even where the built surface has not meaningfully changed.

Outlined areas are visual differences, not confirmed real-world change.

Compare features, not raw pixels.

One shared ResNet18 encoder reads both observations. Geo-Lens takes the absolute difference between their features at several scales, then a U-Net-style decoder reconstructs a full-resolution mask.

Change becomes a location.

Black pixels mean unchanged; white pixels mean predicted change. Because the mask is spatially aligned, it can be placed directly over the later image.

Evaluate once, report honestly.

The selected checkpoint was evaluated across the held-out 128-image test split. Recall is its strongest characteristic; precision shows that false positives remain an important area for improvement.

Aggregate metrics below come from the full test split, not the representative sample.

From experiment to usable instrument.

A FastAPI inference service and Next.js interface let visitors load a curated example or submit PNG, JPEG, or WebP pairs, inspect the mask on the same canvas, and read model, device, inference time, and coverage alongside the result.

Uploads are held in memory only and are not persisted. One process serves the API and static frontend.

A useful baseline, not a finished answer.

Geo-Lens demonstrates credible full-resolution change detection and strong sensitivity to changed areas. Remaining work is to reduce false positives while preserving recall for small buildings.
